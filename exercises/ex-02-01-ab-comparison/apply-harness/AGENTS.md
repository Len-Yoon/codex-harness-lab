# Codex 사용 팁 하네스 규칙

## 목적

Codex 사용 팁을 한국어로 축적 가능한 문서로 정리함.

## 작업 절차

1. 요청 주제와 관련된 공식 OpenAI 문서 또는 직접 실행 가능한 근거를 확인함.
2. 확인한 근거를 `research-notes.md`에 기록함.
3. 팁 하나를 파일 하나로 작성하여 `tips/`에 저장함.
4. `tips/README.md` 인덱스에 항목을 추가함.
5. 아래 형식 준수 여부를 확인함.

## 팁 표준 형식

각 팁 파일은 다음 순서를 사용함.

1. 제목
2. 상황
3. 방법
4. 예시
5. 주의점
6. 출처

## 품질 기준

- 사실은 공식 OpenAI 문서 또는 직접 수행한 명령·화면·로그로 확인함.
- 기능이 현재 환경에서 확인되지 않으면 단정하지 않고 `확인 필요`로 표시함.
- 한 팁에는 하나의 주제만 포함함.
- 추측, 타 도구 전용 명령, 확인되지 않은 단축키는 작성하지 않음.

## 안전 기준

- 커밋·push·외부 서비스 변경은 사용자 요청 없이 수행하지 않음.
- 파일 삭제나 권한 변경을 권장하는 팁에는 복구 방법과 영향 범위를 함께 명시함.
