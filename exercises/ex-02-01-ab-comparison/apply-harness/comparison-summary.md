## 핵심 요약

- A와 B의 핵심 팁 주제는 모두 6개로 동일함.
- B에서 추가된 사항은 새 팁 주제보다 팁별 표준 섹션, 공식 출처, 리서치 기록, 인덱스임.
- B는 재사용과 근거 확인에 유리하나, 단발성 팁 목록에는 문서 수가 증가함.

## 검토 결과

### 하네스 적용으로 추가된 내용

| 항목 | 추가 내용 | 효과 |
|---|---|---|
| 표준 형식 | 상황·방법·예시·주의점·출처 | 팁 문서 간 구성 일관성 확보됨 |
| 공식 근거 | 팁별 OpenAI 공식 문서 링크 | 내용 검토 및 출처 추적 가능함 |
| 리서치 기록 | 6개 주제의 근거 유형·확인 일시·검증 결과 | 팁 작성 근거를 별도 확인 가능함 |
| 인덱스 | 6개 파일 링크와 출처 확인 상태 | 주제별 탐색 및 재사용 가능함 |

| 항목 | A | B | 판단 |

| 주요 메시지 | 명확한 요청, 맥락·제약 제공, 계획·검증, 반복 규칙 관리 | 동일 | 내용 방향은 동일함 |

## 확인 필요 사항

- A·B가 실제로 각각 지정 작업 폴더에서 실행되었는지와 공통 요청문 외 추가 지시가 없었는지는 실행 기록 기준으로 확인 필요함.
- 단발성 요청에서 B의 파일 분리·리서치 기록 비용이 적절한지는 사용 목적에 따라 판단 필요함.
