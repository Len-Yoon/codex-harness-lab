# 반복 규칙은 `AGENTS.md`에 관리하기

## 상황

테스트 명령, 코드 규칙, 금지 사항, 완료 기준처럼 저장소에서 반복되는 지시가 있는 경우에 적용함.

## 방법

저장소의 `AGENTS.md`에 실제 작업에 필요한 규칙과 검증 방법을 간결하게 기록함. 하위 디렉터리에 별도 규칙이 필요하면 해당 디렉터리에 더 구체적인 `AGENTS.md`를 둘 수 있음.

## 예시

```text
AGENTS.md에 다음 항목을 기록함.
- 실행·테스트·린트 명령
- 코드 규칙과 금지 사항
- 완료 기준 및 검증 방법
```

## 주의점

`AGENTS.md`는 짧고 정확하게 유지 필요함. 실제와 다른 규칙이나 모호한 지시가 누적되면 작업 품질을 저해할 수 있으므로 반복 오류가 발생한 경우에만 필요한 규칙을 보완함.
