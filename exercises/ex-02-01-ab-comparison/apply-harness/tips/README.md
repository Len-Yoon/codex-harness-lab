## 작성 규칙

- 팁 하나는 파일 하나로 저장함.
- 파일명은 `kebab-case.md`를 사용함.
- 각 문서는 `상황 → 방법 → 예시 → 주의점 → 출처` 순서를 따름.
- 공식 근거 또는 직접 실행 기록이 없는 항목은 등록하지 않음.
