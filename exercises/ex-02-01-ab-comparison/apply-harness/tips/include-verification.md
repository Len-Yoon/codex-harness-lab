# 검증을 완료 조건에 포함하기

## 상황

코드 또는 설정 변경 후 결과를 검토 가능한 형태로 확인해야 하는 작업에 적용함.

## 방법

요청문에 실행할 테스트·린트·형식 검사 또는 동작 확인을 포함하고, 실행하지 못한 항목은 이유를 함께 보고하도록 지정함.

## 예시

```text
수정 후 관련 테스트와 린트를 실행해 주세요.
실행하지 못한 항목은 이유와 영향 범위를 알려주세요.
```

## 주의점

프로젝트에서 실제 사용하는 검증 명령을 우선 지정 필요함. 검증 명령이나 환경이 없으면 검증 불가 사유와 대체 확인 방법을 분리하도록 요청 필요함.
