# 복잡한 작업은 계획부터 요청하기

## 상황

요구사항이 모호하거나 변경 범위가 넓고 위험 요소를 먼저 검토해야 하는 작업에 적용함.

## 방법

구현 전에 변경 대상, 예상 위험, 검증 방법을 짧은 계획으로 정리하도록 요청하고, 계획을 검토한 뒤 구현을 진행함.

## 예시

```text
구현 전에 변경 대상, 위험 요소, 검증 방법을 짧은 계획으로 정리해 주세요.
계획 확인 후 구현을 진행하겠습니다.
```

## 주의점

작고 명확한 작업에는 계획 단계가 불필요하게 길어질 수 있음. 계획이 필요한 범위와 구현 승인 시점을 요청문에 함께 명시 필요함.
