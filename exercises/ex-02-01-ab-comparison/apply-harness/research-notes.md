# B 실험 리서치 기록

## 기록 목적

팁의 근거와 검증 상태를 남겨, 결과 문서의 출처 신뢰성을 평가할 수 있도록 함.

| No | 주제 | 근거 유형 | 출처 또는 실행 기록 | 확인 일시 | 검증 결과 | 비고 |
|---:|---|---|---|---|---|---|
| 1 |  | 공식 문서 / 직접 실행 |  |  | 확인 완료 / 확인 필요 |  |

## 작성 기준

- 공식 문서는 문서 제목과 직접 URL을 기록함.
- 직접 실행은 실행한 요청, 환경, 관찰 결과를 기록함.
- 근거가 없는 내용은 팁으로 발행하지 않음.
