# 기계 교정 실습 규칙

## 역할

이 폴더의 `copy-editor` agent는 원고의 기계적 교정 3종만 수행함.

## 수정 범위

1. 산문 문장 끝의 불필요한 콜론을 문맥에 맞는 종결 부호로 정리함.
2. `**용어(term)**가`처럼 Bold 마크업 경계 밖으로 나온 한글 조사를 교정함.
3. 중복 음절·중복 어절·명백한 자판 혼용 등 명백한 오탈자를 수정함.

## 예외 및 제한

- 시간 표기의 콜론(`12:30`)은 수정하지 않음.
- 코드 블록 또는 인라인 코드의 콜론은 수정하지 않음.
- 표 헤더·구분 용도의 콜론은 수정하지 않음.
- 의미·논리·구성·문체에 관한 윤문은 하지 않음.
- 모호한 항목은 수정하지 않고 `보류 항목`으로 보고함.
- `practice-target/` 밖의 파일, 설정, Git 상태, 결과 파일은 수정하지 않음.

## 변경 원칙

- 한 줄에 여러 교정이 있으면 가능한 한 작은 단위로 나누어 변경함.
- 변경 전후가 확인 가능하도록 채팅에 수정 내역을 보고함.
- 대상 원고를 읽을 수 없으면 수정하지 않고 즉시 보고함.
